DAILY DEALS ECOMMERCE WEBSITE

This ZIP recreates the supplied Daily Deals reference as a responsive ecommerce front-end.

FEATURES
- Aesthetic left sidebar
- Dashboard
- Shop All
- Bags, Wallets, Perfume, Shoes, Vitamins, Watches
- My Orders
- Wishlist
- Profile
- Settings
- Sale Item
- New Arrival
- Shopping cart panel
- Add Product / Edit Product
- Upload product photos without editing code
- Drag and drop images
- Paste images from clipboard
- Replace / remove images
- Bright, contrast, color, mono and warm image editing
- Zoom, rotate and reset
- Product price and sale price
- Product category, badge, dashboard, new-arrival and sale toggles
- Data persists in browser localStorage

HOW TO USE
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in Chrome/Edge.
4. Use Add Product to manage products.

IMPORTANT
This is a browser-based front-end prototype. Products are stored locally in the browser. It is not yet a production ecommerce backend. A live store needs authentication, database/cloud image storage, inventory, real orders and payment processing.
